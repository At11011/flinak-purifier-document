\subsection{NiCr-3 Specification}
\label{sec:nicr3}
NiCr-3 filler was used to create the weld for the Ni liner. There is
some concern of the corrosion performance in FLiNaK with the high Ni
content. The weld will be
inspected regularly to ensure the integrity of the liner. A specification
from Pinnacle Alloys is provided for reference, but this is not neccesarily
the same provider that Brazos Industries used.
